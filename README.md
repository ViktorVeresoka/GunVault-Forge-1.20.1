# GunVault — Forge 1.20.1

Minecraft Forge mod source and continuous integration.

This repository contains the GunVault project for Minecraft 1.20.1 / Forge 47.4.10, including Glock 17, a 17-round magazine, 9 mm ammunition and underground arsenal world generation.

The source code is provided as `gunvault-ci-payload.zip` and unpacked by the GitHub Actions workflow before building. This is an intermediate source distribution while compilation errors are validated.

A successful workflow publishes a JAR as a build artifact.
